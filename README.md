# Что такое Git?
### Git - это распределённая система управления версиями (Distributed Version Control System, DVCS). Она позволяет разработчикам отслеживать изменения в файлах проекта, хранить их версии и оперативно возвращаться к любому сохранённому состоянию.

# Для чего нужен Git?
### Git нужен для отслеживания изменений, возможности отката к предыдущим версиям, безопасной параллельной работы, совместной работы над проектом, резервного копирования и фиксации авторства
# Команды в Git
## git status
### Эта команда показывает текущее состояние репозитория.
## git init
### Данная команда отвечает за создание нового репозитория.
## git add
### Команда, отвечающая за подготовку изменений к сохранению в репозитории.
## git commit
### Эта команда отвечает за создание нового коммита
# Зачем нужно комментировать коммиты?
### Это нужно, чтобы человек, работающий в вашей команде, понял, что написал каждый из участников.
